# 生长指南

适用于手机与电脑的个人发展工作台。原生 HTML、CSS、JavaScript，无外部依赖。

## 功能

- 12 周路线与每周行动跟进
- 三个真实面试案例整理
- AI 项目与效果实测记录
- 内容选题、发布状态与反馈
- 资金预算与求职机会记录
- 每周复盘与 JSON 备份导入、导出

进度存于当前浏览器的 localStorage。不同设备之间通过导出、导入备份转移，不自动同步。清理站点数据会移除该浏览器记录，请定期备份。

可选起始计划使用 AES-256-GCM 加密；解锁信息仅通过专属 URL 的 fragment 提供，不写入仓库。持有完整专属链接的人可以解锁起始资料；后续修改仅保存在本地。网页不收集账号密码或令牌。

静态部署到 GitHub Pages。通过 HTTPS 打开可使用专属计划解锁与复制入口。
